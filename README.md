# Lifinity Website

The landing page for **Lifinity Financial Services Inc.** at [lifinity.ca](https://lifinity.ca).

- `index.html`: the page (static HTML, CSS and JS; no build step)
- `privacy.html`: privacy notice
- Images in the root: portrait, logos, favicons, share image
- `CLAUDE.md`: brand, copy and compliance rules for Claude Code
- `BUILD-WITH-CLAUDE-CODE.md`: how to go live and how to make changes
- `PLAYBOOK.md`: the design and copywriting principles behind the page

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000.
Deploys to Vercel automatically on every push to `main`.
