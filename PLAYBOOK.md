# Landing page playbook

This is what 24 design and copywriting tutorials taught, and where each lesson shows up on lifinity.ca.

## Structure

| Lesson | Source | On the page |
|---|---|---|
| Hero = value headline, a subline saying how and for whom, a visual, proof, and one CTA | Flux Academy, *Perfect Landing Page Design Explained* | Hero section |
| A service business shows the person you'll work with | Flux Academy | Portrait in the hero, plus the founder note |
| Section order: hero → proof → features → testimonials → CTA → FAQ → footer | Arnau Ros, *9 Sections for the Perfect Landing Page* | Overall order (proof replaced by facts until there are real testimonials) |
| The FAQ answers objections a salesperson would hear in person | Flux Academy | "What people ask before they book" |
| End with one more CTA; never leave the reader without a next step | Flux Academy, Copyhackers | Final band |
| A landing page has one goal; keep the nav minimal | Erik Kennedy (Dive Club), Copyhackers | Four nav links plus one button |
| The nav button and hero button use the same words and go to the same place | Kole Jain, *4 Levels of Landing Page UI/UX* | "Book a call" / "Book a discovery call" |
| Small-business redesigns win by saying who you are, putting logos and proof third, and telling the story with numbers | Flux Academy, *Small Business Websites Redesigned* | Facts row: 5 provinces, RRA®, 14,000+ followers |
| Build from proven sections, then customise | Tim Gabe; Jesse Showalter, *3 F's* | Section patterns |
| Make the first draft fast, then refine; reuse components | Self-Made Web Designer | Shared eyebrow, button and line system |

## Visual craft

| Lesson | Source | On the page |
|---|---|---|
| A recurring **motif** unifies a page | Learn UI Design, *3 design tips* | The L corner and rising copper dots: eyebrows, portrait frame, the four-stage chart |
| Pick a typeface that carries the brand; pair it with a clean sans | Learn UI Design | Spectral (from the wordmark) with Source Sans 3 |
| A personal letter from the founder makes a brand human | Learn UI Design | "A note from G Mon" |
| Edges and alignment make UI feel "weirdly perfect"; emphasis is the difference from neighbours | Kole Jain, *The secret behind weirdly perfect UI* | Left-aligned columns; copper used only for the CTA and the dots |
| Beginner mistakes: harsh shadows, gradients, inconsistent radius and icons, cramped spacing | Kole Jain, *7 UI/UX mistakes* | One 4px radius, no shadows or gradients, generous spacing |
| Don't: sliders, preloaders, full-height heroes, centred long text, vague H1s, scroll-jacking | The Website Architect, *50 Website Design Mistakes* | None of these are used |
| Copy turns from "what it does" into "how it helps" | Kole Jain | "Get a plan before you get a policy" |
| Subtle motion only | Olivier Larose (craft); Website Architect (restraint) | Hover states plus the dots rising once on load |

## Copywriting

| Lesson | Source | On the page |
|---|---|---|
| Three tests: Can I visualise it? Falsify it? Could nobody else say it? | Harry Dry, *Learn Copywriting in 76 Minutes* | "The first thing I tell you is how I'm paid." |
| Write matter of fact, not matter of opinion | Harry Dry, *Copywriting secrets* | 45 minutes, 5 provinces, a written summary, 14 days |
| Juxtaposition: give the reader two choices | Harry Dry, *Same Ad 22 Times*; Eugene Schwartz via Harry Dry | "Starting with a product / Starting with a plan" |
| Have something to say: who it's for, what you're against, why you exist | Harry Dry | "Who I work with", the founder note |
| Ask: would this help a salesperson sell face to face? | Claude Hopkins via Harry Dry | FAQ answers |
| Match the headline to the reader's awareness level | Alex Cattoni, *Headlines that don't suck* | Instagram followers are solution-aware, so a clear next step; cold visitors get the problem and contrast |
| Find your best lines in the customer's own words | Joanna Wiebe / Unbounce, *Landing Page Copy That Sells* | Next step: collect phrases from discovery calls and routing-form answers |
| Real testimonials with full names and photos; never edited claims | Copyhackers, *Conversion Copywriting 101* | Testimonials left out until you have permission |
| PAS (problem, agitate, solution), used gently in financial services | Copyhackers | The "product first" column describes the problem without fear-selling |
